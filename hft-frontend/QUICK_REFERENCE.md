## FAQ

**Q: Do I need the backend?**  
A: No! Frontend works perfectly with mock data.

**Q: Will orders actually execute?**  
A: Mock mode simulates responses. Start backend for real trading.

**Q: Can I deploy this?**  
A: Yes! Deploy to Vercel, Netlify, etc.

**Q: How do I customize colors?**  
A: Edit CSS variables in `src/index.css`
